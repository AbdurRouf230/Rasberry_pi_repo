On the Pi (Debian 13), after cloning:

  cd ~/Rasberry_pi_repo/Debian\ OS\ Yolo
  sed -i 's/\r$//' install_deps.sh
  bash install_deps.sh
  source .venv/bin/activate
  python3 check_camera.py
  python3 bench_camera.py --imgsz 320 --conf 0.35
  python3 bench_images.py --imgsz 320 --conf 0.35

Live window, general 80-class COCO model (person, car, bottle, …).
Run on the Pi desktop / AnyDesk so a window can open:

  python3 live_detect.py --imgsz 320 --conf 0.35

First run downloads yolov8n.pt. q or Esc closes the window.
Writes results/live_YYYYMMDD_HHMMSS/inference.csv, video.mp4,
and one JPEG folder per detected class (person/, car/, …).
Box-only model instead:  python3 live_detect.py --weights weights/best.pt

If install failed with "No space left on device":
  pip pulled CUDA PyTorch (Pi has no NVIDIA GPU). Free space, then rerun:

  cd ~/Rasberry_pi_repo/Debian\ OS\ Yolo
  rm -rf .venv ~/.cache/pip
  sudo apt-get clean
  df -h
  bash install_deps.sh
